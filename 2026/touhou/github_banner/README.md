# Description

The current banner of my Github's profile `README.md` as of writing (`2026-11-25`).
It's a work of two renders in a single piece, both sides are done separately at
separate time.

The left side depicts **Satori Komeiji**, and **Koishi Komeiji** in their **YNPP**'s
outfits.

The right side depicts the **Hifuu Club** duo, **Maribel Hearn**, and **Usami Renko**.

The phrase `Professional Retard` is a nod to my old banner works, it's more of a
satire 'self-description' rather than something to be taken serious of.

The programming languages depicted below are **Rust**, **Luau**, and **C**
(even though the colors looks similar, it is not **HolyC**, unfortunately).
