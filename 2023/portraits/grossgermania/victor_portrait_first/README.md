# Description

The first (modern) render that I've ever done, a simple portrait
that I made for myself to decorate my office in game.

However this isn't the original version of this portrait.
It used to have a **blue** background, before being switched to the
currently-used **Heart of Iron IV** styled portrait background.

The render is done with the works of AI image enhancer and
Photopea's `Oil Paint` filter.
